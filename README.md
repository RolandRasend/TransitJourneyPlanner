Dieses Projekt ist eine Anbindung der Transitous-API um die Verbindungssuche für Bahn- und ÖPNV Verbindungen auf nischigere Anwendungen zuzuschneiden.
Vorläufige Ziele:
- Suche mit Pause nach x Stunden
- Suche mit Übernachtung
- Pause in Parknnähe
- Umstieg mit Zeit ab Bahnhof bestimmte Läden vor nächstem Zug zu erreichen
